Provider strategy

Architecture targets Claude Haiku 4.5 & Sonnet 5 per the cost model above — that's what ships in production, and the token math to the right is priced against those two models.

The running proof-of-concept swaps in free-tier providers so it costs $0 to demonstrate: Groq (openai/gpt-oss-20b) fills the cheap role, Gemini via Google AI Studio (gemini-3.1-flash-lite) fills the quality role — both verified live against real keys after the originally-planned models (llama-3.3-70b-versatile, a gemini-2.5-* model) turned out to be retired/unavailable; see the README. The two-tier routing intent — mechanical work cheap, persuasive drafting expensive — is identical in both configurations.

Provider selection is one config line (config.PROVIDER_MODE). Flip it to "anthropic" and every call routes directly to Claude with no other code change.

Anti-hallucination chain · reply classifier

Ordered so the cheapest, most deterministic gate fails first — schema and keyword checks before model reasoning — minimizing tokens spent on malformed or hostile replies.

1 Injection-marker pre-filter on the raw reply — matches short-circuit to safe-false without calling the model found by red-team
↓
2 Pydantic schema gate — only valid JSON matching the exact 3-field shape reaches the caller
↓
3 Structural evidence check — meeting_requested=true requires a non-empty, verbatim-quoted evidence string, enforced by the schema itself, not just the prompt
↓
4 Injection-marker check on the quoted evidence itself — verbatim-in-reply is necessary but not sufficient, an attacker can plant the phrase they want quoted found by red-team
↓
5 proposed_time stays null unless an explicit time is stated — never inferred
↓
6 Retry once on parse/validation failure
↓
7 Safe-false default on a second failure or any ambiguity — never crash, never guess

Honest limitation: layers 1 and 4 are keyword-based, not a structural guarantee — they close the two exploits a manual red-team pass found (fake-delimiter injection, direct JSON-payload injection, both 5/5 reproducible before the fix, 0/5 after), not every conceivable phrasing. See README § "What red-teaming caught."

Known tradeoff: ambiguous "maybe later" resolves to false — we under-capture rather than over-claim, the correct bias when a false positive means chasing a meeting that was never offered.
